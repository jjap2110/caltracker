# 🔥 CalTracker

Seguimiento de calorías y macros con análisis de fotos por IA.

**100% gratis.** Usa Google Gemini Flash (free tier, sin tarjeta de crédito).

## 🚀 Demo

[https://jjap2110.github.io/caltracker](https://jjap2110.github.io/caltracker)

## ✨ Funcionalidades

- 📸 **Tomar foto**: Usa la cámara para fotografiar tu comida
- 🖼️ **Subir de galería**: Selecciona fotos existentes
- ✏️ **Ingreso manual**: Cuando no tengas foto disponible
- ⚖️ **Peso diario**: Promedio móvil 7 días, tendencia
- 📊 **Ajuste adaptativo**: Alerta si la pérdida es muy rápida/lenta
- 🧮 **Mifflin-St Jeor**: Cálculo preciso de TDEE
- 🎯 **Macros configurables**: Proteína sobre peso actual u objetivo
- 💾 **Export/Import**: Backup JSON de todos los datos
- 📱 **PWA offline**: Funciona sin internet
